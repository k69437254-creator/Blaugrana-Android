# Blaugrana — تجهيز مشروع Android

هذه الحزمة تضع ملف `Blaugrana.html` الأصلي داخل مجلد `www` وتجهّز إعداد Capacitor لبناء تطبيق Android.

## قبل البدء

- ثبّت Node.js 22 أو أحدث.
- ثبّت Android Studio وافتحه مرة واحدة.
- من Android Studio > SDK Manager ثبّت Android SDK Platform وأدوات البناء المناسبة.
- اتصال الإنترنت مطلوب لتنزيل حزم npm وGradle عند أول بناء.

## البناء على Windows

1. فك ضغط ملف ZIP إلى مجلد عادي.
2. افتح المجلد `Blaugrana-Android`.
3. انقر مرتين على `build-apk.bat`.
4. إذا طلب Android Studio تثبيت SDK أو قبول التراخيص، أكمل ذلك ثم أعد تشغيل الملف.
5. عند النجاح سيظهر الملف `Blaugrana-debug.apk` في مجلد المشروع.
6. انقل APK إلى هاتف Android، وافتحه واسمح بالتثبيت من هذا المصدر عند الحاجة.

## البناء على Linux/macOS

من الطرفية داخل مجلد المشروع شغّل:

```bash
./build-apk.sh
```

## البناء السحابي عبر GitHub Actions (اختياري)

ارفع محتويات هذا المجلد إلى مستودع GitHub، ثم افتح تبويب Actions وشغّل `Build Blaugrana APK`. بعد نجاح المهمة نزّل artifact باسم `Blaugrana-debug-apk`؛ يحتوي على APK.

## ملاحظات مهمة حول الوظائف

- هذا يبني نسخة **debug** للتجربة والتوزيع المباشر، وليس نسخة release موقّعة مخصصة للنشر العام.
- راجع الوظائف داخل التطبيق بعد التثبيت.
- فحص المصدر وجد فيه استدعاءات مثل `claude.use("sample")` و`claude.use("db")` و`claude.use("user")` و`claude.use("room")` و`claude.use("assets")`. هذه تبدو معتمدة على بيئة تشغيل خاصة وليست واجهات ويب قياسية. قد تظهر الواجهة، لكن ميزات الذكاء الاصطناعي، الحسابات، قاعدة البيانات المشتركة، الدردشة والرفع لن تعمل تلقائيًا داخل APK ما لم تُربط بواجهات خلفية فعلية أو تُستبدل تلك الاستدعاءات.
- البيانات المخزنة بـ `localStorage` تبقى محلية على الجهاز، ولا تُزامن تلقائيًا بين المستخدمين.
- تأكد من تحديث الأخبار والنتائج والبيانات الرياضية قبل التوزيع؛ وجود بيانات داخل HTML لا يعني أنها مباشرة.
- اسم الحزمة الحالي `com.aram.blaugrana`. غيّره قبل إصدار عام إذا كنت تملك نطاقًا/معرّفًا مختلفًا، وثبّته قبل توزيع التحديثات حتى لا تتعارض نسخ التطبيق.

## الملفات

- `www/index.html`: ملف التطبيق الأصلي.
- `capacitor.config.json`: اسم التطبيق ومعرّفه ومجلد ملفات الويب.
- `package.json`: تبعيات Capacitor.
- `build-apk.bat`: بناء تلقائي على Windows.
- `build-apk.sh`: بناء تلقائي على Linux/macOS.
- `.github/workflows/build-apk.yml`: بناء APK سحابي اختياري.
